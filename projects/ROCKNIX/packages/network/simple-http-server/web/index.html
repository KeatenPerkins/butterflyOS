How to sign in

  1. On your ButterflyOS device, open Settings, then Network Settings.
  2. Select Set SSH Password. Enter a password you will remember and save it.
  3. Turn on Web File Transfer.
  4. When your browser asks, enter root as the username and your new password as the password.

What is root? It is the built-in administrator account name used by ButterflyOS. You do not need to create a separate account.

Choose a folder, then use the upload control on that page. Games uploads use the OS card; Second Game Card writes directly to the card in the second slot. Run Update Gamelists after adding files. For your security, enable Web File Transfer only on a trusted local network.
