# Disabled Butterfly Link patches

These mGBA patches implemented the experimental dual-core, single-core, USB,
and Wi-Fi link-cable paths that were removed from ButterflyOS. They are kept
outside the active `patches/` directory for historical reference only and are
not applied to future builds.

Butterfly Link now means the protected save-management workflow in the
ButterflyOS onboarding package. Normal mGBA GBA emulation remains enabled.
