# Install and manage Blink, Bdex, and Bslap

- [Blink](BUTTERFLY_LINK.md) copies or trades Pokémon between save files and offers event gifts.
- [Bdex](BDEX.md) stores and displays your Pokémon collection, with an optional read-only browser viewer.
- [Bslap](BSLAP.md) lets two devices trade or battle in-game on the same local network.

## Install, update, or remove a tool

On Flip builds with downloadable tools, connect to Wi-Fi and open **Tools → Y Add Tools**.
Manage Tools checks the catalog when it opens. Select a tool and confirm to install it.
The tool appears in the regular **Tools** list once the download and verification finish.

**Installed** appears in green. **Update Available** appears in red when a newer
package is offered. Select the tool to update or remove it. The catalog
automatically selects the package for your device.

## Coming from a build with Btools included

After updating from v1.8.0 or another build with Btools bundled, install the
tools you use once through **Y Add Tools**. Your Bdex collection, shared
sprite cache, and game saves stay on the card. Removing a downloaded tool
also preserves this data. Future OS updates restore the Tools menu entries
for downloaded tools that are still installed.

If you plan to flash a fresh image, back up your collection and saves first.
See [Bdex collection backup](BDEX.md#back-up-or-recover-the-collection) and
[save backup and restore](SAVE_BACKUPS.md).
