# Documentation artwork

These are unmodified copies of approved ButterflyOS artwork and Keaten Perkins's
app icons. Markdown uses explicit display widths so the original OS artwork
does not need to be resized or changed.

- `butterflyos-logo.png`: approved production boot logo from
  `artwork/branding/splash/butterflyos-boot-640x480.png`.
- `games-controller.png`, `media.png`: production artwork from `artwork/ui/`.
- `butterfly-link.png`, `boot-check.png`, `export-recovery.png`,
  `restore-stock.png`, `tools.png`: Keaten's supplied app artwork.
- `home-screen.jpg`: Keaten's device photo showing the home carousel.
- `sd-left.png`, `sd-right.png`: Keaten's slot illustrations for initial setup
  in the stock OS and subsequent ButterflyOS boot, respectively.

The controller image is shared by Games and Controls Guide, as it is in the OS.
No game sprites, ROMs, save files, or credentials are included here. The branding
policy and artwork terms remain those in [the project license](../../BUTTERFLYOS_LICENSE.md).
