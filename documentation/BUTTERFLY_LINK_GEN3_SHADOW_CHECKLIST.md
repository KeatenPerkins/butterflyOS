# Purified Shadow Pokemon gift equivalents

Open **Blink → Local Transfer → Gen 3 → Purified Shadow Gifts**, then choose:

- **Colosseum:** 49 recipes across 48 species; Suicune has Surf and Hydro Pump variants.
- **XD:** 83 recipes.
- **Colosseum e-Reader:** three expanded English equivalents of Japanese-only encounters.

These add an already-purified Pokemon to an empty PC slot in any of the five
qualified English Gen III ROM/save pairs, as if it had been traded to the GBA
game. Shadow capture and purification happen in Colosseum/XD; Blink does not
emulate those mechanics, their story, their saves, or GameCube connectivity.
No Shadow moves or Shadow state are added to GBA games. Lugia has its ordinary
purified appearance, not the dark Shadow Lugia model.

All gifts have the National Ribbon and use trainer BLINK, no held item and the
destination ROM's species data. Colosseum equivalents have normal 1-in-8,192
shiny chance; XD equivalents are non-shiny and retain the modern fateful flag.
The three e-Reader equivalents use zero IVs. Random IVs apply to the other
recipes. Original GameCube PID/IV RNG, identities, language, capture balls,
met locations, heart gauges and purification EXP are not reproduced. Normal
traded-Pokemon obedience rules apply. This is a generated gameplay collection,
not an exact reconstruction of original distributed or captured records.

Duplicate recapture locations are grouped by species, level and full purified
moves. The full reference encounter lists are represented rather than only
species with exclusive moves. No ROMs, saves, original Pokemon records, card
scans or sprite caches are bundled. Sprites and game data come from the user's
matching qualified ROM, using the existing Blink cache.

## Test procedure

Save normally and exit the game before using Blink. Choose a source group,
destination save and matching ROM, then a gift and empty PC slot. Inspect the
preview and explicitly Commit. Existing verified backups, cancellation,
changed-save refusal and repeated-Commit refusal apply.

Check the species, level, moves and National Ribbon, withdraw it, use it in a
battle, then save and reload normally. Good distinctive XD checks include
Lugia's Psycho Boost/FeatherDance, Dragonite's Heal Bell and the legendary birds'
Extrasensory. Check both Suicune variants and all three e-Reader options.
Ordinary test gifts will almost always be non-shiny even where shiny chance is
allowed; automated checks deliberately exercise shiny candidates.

Automated checks passed 5,940 recipe/layout/game combinations and 675 protected
commits across all five games. Emerald covers all 24 encrypted record layouts;
the other four games cover five representative layouts each. Live installation
and file hashes were verified on the local test device. The user confirmed the purified gifts working on the local test device. Individual recipes, destination games and ribbon/battle/save checks were not enumerated; this is not an exhaustive per-recipe/per-game qualification. The fixture catalog records the exact
reference snapshots. Automated tests independently decrypt records, check move
PP/EXP/ribbons/fateful and egg bits, compare exact write boundaries, invoke the
native reader and exercise protected Commit on disposable saves.
